# GPU Acceleration with RAPIDS cuGraph & cuML

Spatial transcriptomics datasets generated by modern platforms (such as 10x Genomics Xenium, Vizgen MERSCOPE, and Stereo-seq) often exceed 100,000 to millions of cells. Building spatial adjacency graphs (k-NN or fixed-radius queries) on CPU can become a significant bottleneck.

`spatial_pipeline` integrates **RAPIDS cuML** and **cuGraph** to offload nearest-neighbor querying, edge generation, and Graph Laplacian construction directly to NVIDIA CUDA GPUs.

---

## Capabilities

1. **GPU k-NN Graph Construction**:
   Utilizes `cuml.neighbors.NearestNeighbors` for massive GPU nearest-neighbor search.

   ```python
   import spatial_pipeline as sp

   # Construct k-NN graph on GPU with backend="cuml"
   adj_matrix, laplacian = sp.build_knn_graph(
       bin_coords, 
       n_neighbors=15, 
       backend="cuml"
   )
   ```

2. **GPU Radius Graph Construction**:
   Supports fixed-radius queries on GPU via cuML/cuGraph.

   ```python
   adj_matrix, laplacian = sp.build_spatial_graph(
       bin_coords, 
       max_distance=15.0, 
       backend="cugraph"
   )
   ```

3. **Graceful CPU Fallback**:
   When `backend="auto"` is specified, `spatial_pipeline` checks GPU availability via `sp.is_gpu_available()` and automatically selects GPU acceleration if available, falling back to multi-core CPU parallel execution otherwise.
